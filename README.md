# FinLens AI · น้อง Lensy

ผู้ช่วยอ่านเอกสารกองทุนรวม ทั้งใน LINE และบนเว็บ น้อง Lensy (แพนด้าแดงตัวสีเขียว) อ่าน Fund Fact Sheet กับหนังสือชี้ชวนให้ แล้วบอกเป็นภาษาง่าย ๆ ว่า **มีค่าใช้จ่ายอะไร เสียเงินไปกี่บาท และมีความเสี่ยงอะไร** ทุกตัวเลขบอกที่มา

น้อง Lensy มีหน้าที่ 3 อย่าง

1. **เทียบกองทุนเคียงกัน (หัวใจของ FinLens):** เช่น กองที่ลงทุนต่อในกองต่างประเทศกับกองดัชนี ว่าแต่ละกองมีค่าธรรมเนียมที่มองไม่เห็นอะไรบ้าง ซ่อนอยู่หน้าไหนของเอกสาร และถือไว้หลายปีแล้วต่างกันกี่บาท โดยไม่ตัดสินว่ากองไหนดีกว่า
2. **อธิบายทีละกองเป็นภาษาง่าย:** กองนี้มีค่าใช้จ่ายอะไร เสียเงินไปกี่บาท และมีความเสี่ยงอะไร
3. **ตอบคำถามเรื่องการเงิน:** อธิบายศัพท์และแนวคิดการเงินทั่วไป โดยติดป้ายว่าเป็นความรู้ทั่วไป ส่วนตัวเลขของกองตอบจากเอกสารที่ทีมตรวจแล้วเท่านั้น

นอกจากนี้ยังมีข้อมูลอ้างอิงการลงทุน 10 หมวด (ตลาดเงิน ตราสารหนี้ หุ้น กองทุนรวม ETF สินค้าโภคภัณฑ์ อนุพันธ์ สินทรัพย์ดิจิทัล FX ต่างประเทศ) ที่ดู เทียบ คำนวณ และถามน้อง Lensy ได้ด้วยหลักเดียวกัน คือทุกตัวเลขบอกวันที่ สถานะการตรวจสอบ และแหล่งที่มา

> ข้อมูลเพื่อความเข้าใจ ไม่ใช่คำแนะนำการลงทุน

- เว็บ: https://lensy-fin-lens-ai.vercel.app (ดูกอง เทียบ และคำนวณได้โดยไม่ต้องล็อกอิน แชตกับน้อง Lensy ต้องล็อกอินด้วย LINE)

## ปัญหาในตัวเลขเดียว

กองทุนรวมที่ลงทุนต่อในกองต่างประเทศ (feeder fund) มีค่าใช้จ่าย 2 ชั้น แต่ Factsheet ของกองไทยแสดงแค่ชั้นเดียว

| | KFUS-A (กองเชิงรุก ลงทุนผ่านกองหลัก) | K-US500X-A(A) (กองดัชนี S&P 500) |
|---|---|---|
| TER ที่เห็นใน Factsheet | 1.54% ต่อปี (Factsheet หน้า 2) | 0.64% ต่อปี (Factsheet หน้า 2) |
| ค่าใช้จ่ายกองหลักที่ไม่อยู่ใน Factsheet | 0.55% ต่อปี (หนังสือชี้ชวน หน้า 5) | 0.03% ต่อปี (หนังสือชี้ชวน หน้า 42) |
| **ต้นทุนต่อปีรวม** | **2.09%** | **0.67%** |
| ค่าธรรมเนียมรวมเป็นเงิน ลงทุน 100,000 บาท 10 ปี | 36,275 บาท | 11,852 บาท |
| ลงทุน 100,000 บาท 20 ปี | 113,663 บาท | 40,627 บาท |

ทั้งสองกองลงทุนหุ้นสหรัฐฯ ระดับความเสี่ยง 6 เท่ากัน แต่ถือ 10 ปีเสียค่าธรรมเนียมต่างกันราว **24,000 บาท** และ 20 ปีราว **73,000 บาท**
(สมมติผลตอบแทนก่อนหักค่าใช้จ่าย 6% ต่อปี รวมค่าธรรมเนียมขายและรับซื้อคืน ข้อมูล Factsheet ณ 30 ก.ย. 2569 คำนวณด้วย `src/lib/trueCost.ts` ไม่ได้ให้ AI คิด)

| **AI Explain** | ถามเรื่องกอง หัวข้อการลงทุน ศัพท์ หรือความรู้การเงินทั่วไป ระบบหากองและหัวข้อจากคำถามเอง ตัวเลขของกองและหัวข้อบอกที่มา | คำถามขอคำแนะนำ (ไทยและอังกฤษ) → ปฏิเสธด้วยกฎ · คำถามตัวเลขเงิน → `trueCost` · อื่น ๆ → Gemini แล้วโค้ดตรวจว่าตัวเลขของกองทุกตัวมีที่มา และคำตอบไม่มีคำแนะนำหรือสัญญาผลตอบแทน · `src/lib/askService.ts` |

### กติกา Responsible AI ที่ระบบบังคับใช้
1. ทุกตัวเลขบอกที่มา: ข้อมูลที่ดึงจาก PDF ต้องมีเลขหน้าและข้อความอ้างอิง ข้อมูลที่นำเข้าจากตาราง (`npm run import-funds`) บอกแหล่ง และได้ป้าย "ตรวจกับเอกสารแล้ว" เฉพาะเมื่อมีเลขหน้าครบ ข้อมูลอ้างอิงการลงทุนบอกวันที่และสถานะการตรวจสอบ ส่วนคำอธิบายความรู้ทั่วไปใช้ตัวเลขสมมติได้ 1 ตัวอย่าง และติดป้ายว่าเป็นความรู้ทั่วไป
2. เอกสารไม่มี → "ไม่พบข้อมูลนี้ในเอกสาร" ไม่เดา
3. ไม่แนะนำซื้อขาย ไม่จัดอันดับ ไม่คาดการณ์ผลตอบแทน: กฎจับคำถามก่อนถึง AI และตรวจคำตอบของ AI ซ้ำอีกรอบ ถ้าเจอคำแนะนำหรือการสัญญาผลตอบแทน คำตอบจะถูกแทนด้วยข้อความปฏิเสธ
4. เว็บและ LINE อ่านเฉพาะ `data/verified/` และข้อมูลกองจริงที่นำเข้า (`data/funds/real/funds.json`) ไม่อ่าน `data/extracted/`
5. การ์ดคำตอบใน LINE มีบรรทัด "ไม่ใช่คำแนะนำการลงทุน"
6. ไม่มีฐานข้อมูลสมาชิก คุกกี้เก็บแค่ LINE userId แบบ hash
7. ข้อมูลตัวอย่างติดป้าย "ข้อมูลตัวอย่าง" ทุกที่
8. จำกัดคำถามต่อคน (8 ข้อต่อนาที ทั้งเว็บและ LINE) และเก็บคำตอบที่ตรวจแล้วไว้ 1 ชั่วโมงในหน่วยความจำ คนเดียวจึงใช้โควตา AI จนหมดสำหรับทุกคนไม่ได้ · `src/lib/rateLimit.ts`

## น้อง Lensy ใน LINE
- พิมพ์ชื่อหรือรหัสกอง (หรือ "เทียบ A กับ B") → การ์ดสรุปต้นทุนรวม ความเสี่ยงหลัก ที่มาของตัวเลข และปุ่ม "ดูละเอียด" (เปิดหน้าเว็บใน LINE)

## สถาปัตยกรรม

แอป **Next.js 15** ตัวเดียวในโฟลเดอร์ `frontend/` มีทั้งหน้าเว็บและ backend (API routes + โค้ดฝั่งเซิร์ฟเวอร์) deploy บน Vercel
อ่านแบบละเอียดพร้อมแผนภาพได้ที่ **[docs/architecture.md](docs/architecture.md)**

```
LINE app ──webhook──▶ /api/line/webhook ─┐
                                         ├─▶ หากอง/หัวข้อจากคำถาม ─▶ askService ─┬─ กฎ: ปฏิเสธคำแนะนำ
เว็บ (Next.js) ───────▶ /api/ask ─────────┘                                     ├─ สูตร: ตัวเลขเงิน
                                                                               └─ Gemini + ตรวจตัวเลขทุกตัว
ข้อมูล: data/verified · data/funds/real · reference-data.json (ไฟล์ใน repo ตรวจด้วย Zod ไม่มีฐานข้อมูล)
```

- **Backend:** `src/app/api/` (ask, auth, line/webhook), `src/middleware.ts`, `src/lib/` (askService, ai, trueCost, rateCalc, riskRules, subjects, reference)
- **AI:** Gemini API (`@google/genai`) รุ่น `gemini-3.5-flash-lite` เปลี่ยนได้ด้วย `GEMINI_MODEL`
- **LINE:** Messaging API (`@line/bot-sdk`) + LIFF (`@line/liff`)
- **UI:** Tailwind CSS, Recharts, lucide-react
- **ทดสอบ:** Vitest

## วิธีรันในเครื่อง

ต้องมี Node.js 20+ (ใช้ pnpm ผ่าน `npx pnpm`)

```bash
cd frontend
npx pnpm@10 install
cp .env.example .env.local   # แล้วใส่ค่า (ดูด้านล่าง)
npm run dev                  # http://localhost:3000
npm test                     # unit tests
npm run build
```

บนเครื่องพัฒนา หน้าล็อกอินมีปุ่ม **"เข้าโหมดทดลอง"** สำหรับเข้าแดชบอร์ดโดยไม่ใช้ LINE (เว็บจริงที่ตั้ง LIFF แล้วจะไม่มีปุ่มนี้)

### ค่าใน `.env.local` (และใน Vercel)
| ชื่อ | ใช้ทำอะไร |
|---|---|
| `GEMINI_API_KEY`, `GEMINI_MODEL` | AI (Gemini API ของ Google ค่าเริ่มต้น `gemini-3.5-flash-lite`) |
| `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN` | บอท LINE (Messaging API channel) |
| `NEXT_PUBLIC_LIFF_ID` | ล็อกอินด้วย LINE และเปิดเว็บใน LINE |
| `LINE_LOGIN_CHANNEL_ID` | (ไม่บังคับ) channel ของ LINE Login ถ้าไม่ตั้งใช้ส่วนหน้าของ LIFF ID |
| `NEXT_PUBLIC_SITE_URL` | URL ของเว็บ เช่น `https://lensy-fin-lens-ai.vercel.app` |
| `SESSION_SECRET` | เซ็นคุกกี้ล็อกอิน (สุ่มยาว ๆ บนเว็บจริงต้องมี) |
| `NEXT_PUBLIC_LINE_ADD_FRIEND_URL` | ปุ่มเพิ่มเพื่อน |

ห้าม commit `.env.local`

## วิธีเพิ่มกองทุน

1. วาง PDF ที่ `frontend/docs/pdfs/<รหัสกอง>/` (ชื่อไฟล์มีคำว่า `fact` = Factsheet, ไฟล์อื่น = หนังสือชี้ชวน; ชื่อโฟลเดอร์ไม่มี `&` หรือเว้นวรรค)
2. `npm run extract -- <รหัสกอง>` → ได้ `data/extracted/<รหัสกอง>.json` สถานะ `pending`
   ระบบตรวจซ้ำว่าข้อความอ้างอิงมีอยู่จริงในหน้านั้น ถ้าไม่เจอค่านั้นจะเป็น `null` และอยู่ในรายการ "สิ่งที่ต้องตรวจเอง"
3. ทีม econ ตรวจทีละค่าเทียบกับ PDF ตาม [frontend/data/README.md](frontend/data/README.md)
4. ตั้ง `"status": "verified"` และ `"verifiedBy"` แล้วย้ายไฟล์ไป `data/verified/`
5. `npm test` และ `npm run build` แล้ว commit

## ตั้งค่า LINE
1. **Messaging API channel:** Webhook URL = `https://<เว็บ>/api/line/webhook` → Verify → เปิด Use webhook
2. **LINE Official Account Manager:** ปิด Auto-reply และ Greeting messages
3. **LINE Login channel → LIFF:** Endpoint URL และ Callback URL = `https://<เว็บ>`, Scope `openid` + `profile`, Size Full
4. เมนูล่างแชต: `npm run line:richmenu` (ดูรูป) และ `npm run line:richmenu -- --apply` (ตั้งจริง)
5. เปลี่ยนการ์ดแล้ว: `npm run line:validate` ให้ LINE ตรวจรูปแบบ (ไม่ได้ส่งข้อความหาใคร)

## ข้อจำกัดที่รู้อยู่แล้ว

- **ตรวจละเอียดได้ 3 กอง:** กองที่ตรวจกับ PDF ทีละค่าพร้อมเลขหน้ามี 3 กอง อีก 19 กองมาจากตารางที่ทีมกรอก บางค่ายังไม่มีเลขหน้า และระบบติดป้าย "รอตรวจเลขหน้า" ไว้
- **ข้อมูลอ้างอิงยังตรวจไม่ครบ:** 49 จาก 123 หัวข้อยังไม่ตรวจ หน้าเว็บแสดงป้ายบอก และน้อง Lensy ไม่ใช้หัวข้อเหล่านี้ตอบ
- **อัปเดตด้วยมือ:** ยังไม่ดึง Factsheet ฉบับใหม่อัตโนมัติ ต้องวาง PDF แล้วให้ทีมตรวจ (ดู "วิธีเพิ่มกองทุน")
- **กฎจับคำถามเป็นคำที่ตั้งไว้:** คำถามขอคำแนะนำที่เขียนแปลกออกไปอาจหลุดไปถึง AI ได้ จึงมีการตรวจคำตอบของ AI อีกชั้นหนึ่ง แต่ก็ยังเป็นการจับคำ ไม่ได้รับประกันว่าครบทุกกรณี
- **โควตา AI:** ใช้ Gemini API ถ้าโควตาเต็ม น้อง Lensy จะบอกให้รอ แต่การ์ดกองและตัวเลขเงินยังตอบได้ เพราะไม่ใช้ AI การจำกัดคำถามและแคชคำตอบเก็บในหน่วยความจำของแต่ละเซิร์ฟเวอร์ จึงไม่แม่นเมื่อมีหลายเครื่อง
