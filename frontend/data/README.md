# ข้อมูลกองทุน: ดึง → ตรวจ → ใช้งาน

```
docs/pdfs/<รหัสกอง>/      PDF ต้นฉบับ (Factsheet + หนังสือชี้ชวน)
        │  npm run extract -- <รหัสกอง>
        ▼
data/extracted/<รหัสกอง>.json   สถานะ "pending" รอคนตรวจ (เว็บและ LINE ไม่อ่านโฟลเดอร์นี้)
        │  ทีม econ ตรวจทีละค่า แล้วย้ายไฟล์
        ▼
data/verified/<รหัสกอง>.json    สถานะ "verified" เว็บและ LINE อ่านจากที่นี่เท่านั้น
```

## 1. ดึงข้อมูลจาก PDF

1. วาง PDF ไว้ที่ `docs/pdfs/<รหัสกอง>/` ไฟล์ที่ชื่อมีคำว่า `fact` คือ Factsheet ไฟล์อื่นถือเป็นหนังสือชี้ชวน
2. ใส่ `GEMINI_API_KEY` ใน `.env.local` (key ของ Gemini API จาก Google AI Studio)
3. รันในโฟลเดอร์ `frontend/`

   ```
   npm run extract -- <รหัสกอง>
   ```

สคริปต์ดึงข้อความจาก PDF ทีละหน้า ส่งให้ Gemini หาค่าพร้อมเลขหน้าและข้อความอ้างอิง แล้ว**ตรวจซ้ำว่าข้อความอ้างอิงมีอยู่จริงในหน้านั้น** ถ้าไม่เจอ ค่านั้นจะเป็น `null` รายการ "สิ่งที่ต้องตรวจเอง" จะพิมพ์ท้ายผลลัพธ์ และอยู่ใน `meta.notes` ของไฟล์ด้วย

PDF ที่เป็นภาพสแกนดึงข้อความไม่ได้ สคริปต์จะเตือน ให้หาไฟล์ที่เป็นข้อความแทน

## 2. ตรวจทีละค่า (ทีม econ)

ทุกค่าเป็นรูปแบบนี้

```json
"ter": { "value": 1.07, "page": 2, "quote": "ค่าใช้จ่ายรวมทั้งหมด 1.07%", "source": "factsheet" }
```

สำหรับแต่ละค่า ให้เปิด PDF ตาม `source` ไปที่หน้า `page` แล้วเช็ก 4 ข้อ

- [ ] `quote` มีอยู่จริงในหน้านั้น
- [ ] `value` ตรงกับ `quote` และหน่วยถูก (ค่าธรรมเนียมเป็น % ตามที่เขียน เช่น `1.07` ไม่ใช่ `0.0107`)
- [ ] ค่าธรรมเนียมเป็นค่า **"เก็บจริง"** ไม่ใช่ "สูงสุดไม่เกิน"
- [ ] ถ้าเอกสารไม่มีข้อมูล ให้เป็น `{ "value": null, "page": null, "quote": null, ... }` ห้ามเติมเอง

จุดที่ต้องดูเป็นพิเศษ

- `fees.masterFundExpense` และ `fees.terIncludesMasterFund`: Factsheet ของกองไทยไม่ได้แสดงค่าใช้จ่ายกองหลัก ต้องไปหาจากเอกสารของกองหลักต่างประเทศ (หรืออยู่ในหนังสือชี้ชวน) ตัวเลขนี้ใช้คำนวณ "ต้นทุนต่อปีรวม" โดยตรง
- `page` คือ **ลำดับหน้าของไฟล์ PDF** (หน้าแรกของไฟล์ = 1) ซึ่งอาจไม่ตรงกับเลขหน้าที่พิมพ์ไว้บนกระดาษ
- ค่าที่อยู่ใน `meta.notes` ว่า "หาข้อความอ้างอิงในเอกสารไม่เจอ" ถูกตั้งเป็น `null` ไว้ ถ้าเจอในเอกสาร ให้เติม `value`, `page`, `quote` เองให้ครบทั้งสามช่อง

## 3. ย้ายไป verified

1. แก้ใน `meta`
   - `"status": "verified"`
   - `"verifiedBy": "<ชื่อผู้ตรวจ>"`
   - ลบข้อความใน `notes` ที่จัดการแล้ว
2. ย้ายไฟล์จาก `data/extracted/` ไป `data/verified/`
3. รัน `npm test` และ `npm run build` ถ้าไฟล์ผิดรูปแบบ (เช่น มี `value` แต่ไม่มี `page`) จะไม่ผ่าน และบอกว่าผิดที่ไฟล์ไหน

## ข้อมูลตัวอย่าง

`SAMPLE-GLOBAL.json` และ `SAMPLE-INDEX.json` เป็นกองสมมติ (`"isSample": true`) ใช้สาธิตระหว่างรอข้อมูลจริง ทุกที่ที่แสดงต้องติดป้าย "ข้อมูลตัวอย่าง" เมื่อมีกองจริงครบแล้วลบสองไฟล์นี้ได้
