# กองทุนลดหย่อนภาษี: คำอธิบายมาตรฐานของ FinLens

ไฟล์นี้เป็นแหล่งเดียวที่น้อง Lensy ใช้ตอบคำถามเรื่อง RMF, SSF, Thai ESG และการลดหย่อนภาษี
AI สรุปจากไฟล์นี้เท่านั้น ห้ามตอบเงื่อนไขเอง และทุกคำตอบต่อท้ายว่าเงื่อนไขอาจเปลี่ยนตามปีภาษี

วิธีแก้ไข (สำหรับทีม)
- บรรทัดที่มีคำว่า TODO จะ **ไม่ถูกส่งให้ AI** จนกว่าทีมจะตรวจแล้วลบคำว่า TODO ออก
- ใส่ตัวเลขเงื่อนไข (ระยะเวลาถือ เพดานลดหย่อน ปีภาษีที่ใช้ได้) เฉพาะที่ตรวจกับแหล่งทางการแล้ว พร้อมลิงก์และวันที่ตรวจ
- ถ้าตัวเลขใดยังไม่ได้ตรวจ ให้คงเป็น TODO ไว้ AI จะตอบว่ายังไม่มีในคำอธิบายมาตรฐาน และให้ผู้ใช้ตรวจกับ ก.ล.ต. หรือกรมสรรพากร

ตรวจล่าสุดโดย: TODO (ชื่อผู้ตรวจ) · วันที่ตรวจ: TODO · ปีภาษีที่อ้างอิง: TODO

## การลดหย่อนภาษีด้วยกองทุนทำงานอย่างไร

- เงินที่ซื้อกองทุนลดหย่อนภาษีนำไปหักออกจากเงินได้ก่อนคำนวณภาษี ไม่ได้แปลว่าได้เงินภาษีคืนเท่ากับเงินที่ซื้อ
- ภาษีที่ประหยัดได้จริงขึ้นกับฐานภาษีของแต่ละคน คนที่เสียภาษีในอัตราสูงกว่าจะประหยัดได้มากกว่าเมื่อซื้อเท่ากัน
- กองทุนลดหย่อนภาษีแต่ละแบบมีเงื่อนไขของตัวเอง เช่น ต้องถือให้ครบระยะเวลา และมีเพดานจำนวนเงินที่นำไปลดหย่อนได้ต่อปี
- ถ้าขายก่อนครบเงื่อนไข อาจต้องคืนภาษีที่เคยได้ลดหย่อนไป และอาจมีเงินเพิ่มตามที่กรมสรรพากรกำหนด
- กองทุนลดหย่อนภาษีก็มีค่าธรรมเนียมและความเสี่ยงตามนโยบายการลงทุนของกองนั้นเหมือนกองทั่วไป ควรดูค่าใช้จ่ายทุกชั้นด้วย
- TODO ลิงก์หน้าทางการของกรมสรรพากรเรื่องค่าลดหย่อนจากการซื้อกองทุน (https://www.rd.go.th/...) และวันที่ตรวจ

## RMF (กองทุนรวมเพื่อการเลี้ยงชีพ)

- เป้าหมาย: ออมเงินระยะยาวไว้ใช้หลังเกษียณ
- ลงทุนได้หลายแบบตามนโยบายของแต่ละกอง เช่น หุ้น ตราสารหนี้ หรือผสม ความเสี่ยงจึงต่างกันมากระหว่างกอง
- เงินที่ซื้อนำไปลดหย่อนภาษีได้ตามเงื่อนไขของปีภาษีนั้น
- ต้องถือตามระยะเวลาและอายุที่กฎหมายกำหนดก่อนขายได้โดยไม่ผิดเงื่อนไข
- TODO ระยะเวลาถือขั้นต่ำ และอายุขั้นต่ำก่อนขายได้ (ตรวจกับ ก.ล.ต. / สรรพากร)
- TODO เพดานลดหย่อนต่อปี (สัดส่วนของเงินได้ และวงเงินสูงสุด รวมกับกลุ่มเกษียณอื่น)
- TODO เงื่อนไขการซื้อต่อเนื่อง (ต้องซื้อทุกปีหรือไม่)
- TODO ลิงก์ ก.ล.ต. (https://www.sec.or.th/...) และสรรพากร

## SSF (กองทุนรวมเพื่อการออม)

- เป้าหมาย: ออมระยะยาว ไม่ได้จำกัดว่าต้องใช้หลังเกษียณ
- ลงทุนได้หลายแบบตามนโยบายของแต่ละกอง
- สิทธิลดหย่อนภาษีของ SSF ใช้ได้เฉพาะปีภาษีที่กฎหมายกำหนด ต้องตรวจว่าปีภาษีปัจจุบันยังลดหย่อนได้หรือไม่
- TODO ปีภาษีที่ยังลดหย่อนได้ หรือวันที่สิทธิสิ้นสุด (ตรวจกับสรรพากร)
- TODO ระยะเวลาถือขั้นต่ำ
- TODO เพดานลดหย่อนต่อปี
- TODO ลิงก์ ก.ล.ต. และสรรพากร

## Thai ESG (กองทุนรวมไทยเพื่อความยั่งยืน)

- เป้าหมาย: ส่งเสริมการลงทุนระยะยาวในหลักทรัพย์ไทยที่ใส่ใจสิ่งแวดล้อม สังคม และธรรมาภิบาล (ESG)
- ลงทุนในหุ้นหรือตราสารหนี้ของไทยที่เข้าเกณฑ์ด้านความยั่งยืนตามที่กำหนด
- เงินที่ซื้อนำไปลดหย่อนภาษีได้ตามเงื่อนไขของปีภาษีนั้น และเงื่อนไขของ Thai ESG มีการปรับในบางปี
- TODO ระยะเวลาถือขั้นต่ำสำหรับเงินที่ซื้อในปีภาษีนี้
- TODO เพดานลดหย่อนต่อปี
- TODO ปีภาษีที่โครงการเปิดให้ลดหย่อน
- TODO ลิงก์ ก.ล.ต. และสรรพากร

## ก่อนซื้อกองทุนลดหย่อนภาษี ควรเช็กอะไร

- เงื่อนไขของปีภาษีนั้นจากแหล่งทางการ (ก.ล.ต. และกรมสรรพากร) หรือหนังสือชี้ชวนของกองที่สนใจ
- รวมเงินที่ซื้อกองลดหย่อนทุกกองแล้วยังไม่เกินเพดานของแต่ละแบบ และเพดานรวม
- ค่าใช้จ่ายทุกชั้นของกอง (ค่าธรรมเนียมการขาย TER และค่าใช้จ่ายกองหลักถ้าเป็นกองฟีดเดอร์)
- ความเสี่ยงตามนโยบายการลงทุน เพราะต้องถือยาวตามเงื่อนไข
