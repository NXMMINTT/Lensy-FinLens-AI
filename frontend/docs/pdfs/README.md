# PDF กองทุน

วางไฟล์ของแต่ละกองไว้ในโฟลเดอร์ชื่อรหัสกอง (ตัด `&` และเว้นวรรคออก เช่น SCBS&P500A → `SCBSP500A` เพราะเครื่องหมายเหล่านี้ทำให้คำสั่งในเทอร์มินัลพัง)

```
docs/pdfs/
  SCBSP500A/
    factsheet.pdf      ← ชื่อไฟล์มีคำว่า "fact" = Fund Fact Sheet
    prospectus.pdf     ← ไฟล์อื่น = หนังสือชี้ชวน (ฉบับเต็ม)
```

- ใช้ฉบับล่าสุดจากเว็บของบลจ. หรือ ก.ล.ต.
- ควรมีหนังสือชี้ชวนฉบับเต็มด้วย เพราะค่าใช้จ่ายของกองทุนหลักมักอยู่ในนั้น
- ขนาดรวมต่อกองไม่เกินราว 30 MB

จากนั้นรัน `npm run extract -- <รหัสกอง>` ดูขั้นตอนตรวจที่ `data/README.md`
