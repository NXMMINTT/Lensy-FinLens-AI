## ประโยคที่ตอบเกณฑ์การให้คะแนน

| เกณฑ์ | ประเด็นที่พูด |

| **Innovation** | รวมค่าใช้จ่ายทุกชั้น + เลขหน้าที่กดดูข้อความจริงได้ + คุยผ่าน LINE ที่คนไทยใช้อยู่แล้ว |
| **Technical Feasibility** | ทำงานจริงบนเว็บและ LINE, AI อ่านเอกสาร แต่โค้ดตรวจซ้ำว่าข้อความอ้างอิงมีอยู่จริงในหน้านั้น, unit test 230 ข้อ |
| **Business Value** | ตอนนี้ฟรีใน LINE · แผนถัดไป: Premium 99 บาท/เดือน (ส่องทั้งพอร์ต, เช็กก่อนเชื่อ) ยังไม่ได้สร้างในแอป ให้พูดว่าเป็นแผน · ต่อยอดให้ บลจ. หรือแพลตฟอร์มขายกองทุนใช้ได้ |
| **Responsible AI** | ไม่แนะนำซื้อขาย ไม่จัดอันดับ ไม่คาดการณ์, ตัวเลขเงินคิดด้วยสูตร, ไม่พบก็บอกว่าไม่พบ, ข้อมูลผ่านการตรวจโดยคนก่อนใช้, ไม่เก็บข้อมูลส่วนตัว |

## ถ้ากรรมการถาม

- **"AI ตอบผิดได้ไหม"** → AI ใช้แค่ช่วยอ่านเอกสารและอธิบาย ทุกค่าที่ AI ดึงมา โค้ดจะตรวจว่าข้อความอ้างอิงมีอยู่จริงในหน้านั้น และทีมตรวจทีละค่าก่อนนำขึ้นระบบ ตัวเลขเงินคิดด้วยสูตร ไม่ใช่ AI
- **"ทำไมไม่บอกว่ากองไหนดี"** → การแนะนำการลงทุนต้องมีใบอนุญาต และขึ้นกับเป้าหมายของแต่ละคน เราให้ข้อมูลเปรียบเทียบที่ตรวจสอบได้แทน
- **"ข้อมูลอัปเดตยังไง"** → วาง PDF ฉบับใหม่ รันคำสั่งเดียว ทีมตรวจแล้วกดยืนยัน ระบบแสดงวันที่ของข้อมูลทุกกอง
- **"ถ้าถามอ้อม ๆ เช่น มีเงินแสนนึงลงอะไรดี / Should I buy"** → กฎจับได้ทั้งไทยและอังกฤษก่อนถึง AI และถ้า AI ยังเขียนคำแนะนำหรือสัญญาผลตอบแทนออกมา โค้ดตรวจคำตอบอีกรอบแล้วแทนด้วยข้อความปฏิเสธ
- **"ถ้ากรรมการหลายคนถามพร้อมกัน AI ล่มไหม"** → คำตอบที่ตรวจแล้วเก็บไว้ 1 ชั่วโมง คำถามซ้ำไม่เรียก AI อีก และจำกัด 8 คำถามต่อนาทีต่อคน ถ้า AI ไม่ว่าง น้องบอกให้รอ และการ์ดกองกับตัวเลขเงินยังตอบได้ทันทีเพราะไม่ใช้ AI
- **"เก็บข้อมูลผู้ใช้ไหม"** → ไม่มีฐานข้อมูลสมาชิก ล็อกอินด้วย LINE เก็บแค่รหัสที่แปลงแล้วย้อนกลับไม่ได้
